# Structural Framing releases

Releases of the Structural Framing add-in for Autodesk Fusion 360, published by mecafrog.com.

The add-in's Settings > About > Check for Updates button reads this repository's latest
release to tell you when a newer version exists. It downloads and installs nothing; you
run the installer attached to the release yourself.

Product page and pricing: https://www.mecafrog.com/f360-addins/structural-framing/pricing.html
